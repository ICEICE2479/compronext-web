# 🚀 ComproNext Web - วิธีเปิดใช้งานเว็บแบบครบจบ

ไฟล์โปรเจกต์นี้ได้รับการคลีนและบรรจุทุกฟังก์ชันของระบบไว้ครบถ้วน (หน้าบ้าน + หลังบ้าน + สตูดิโอจัดห้อง 3D + AI + สินค้าจำลอง 2,100+ ชิ้น) โดยตัดไฟล์ขยะและประวัติ git ทิ้ง ทำให้มีน้ำหนักเบาและพร้อมใช้งานทันที

---

## วิธีที่ 1: ดับเบิลคลิกเปิดใช้งานในเครื่อง (ง่ายที่สุด 1-Click) 🌟

### สำหรับ Windows:
- **ดับเบิลคลิกไฟล์ `start.bat`**
- ระบบจะตรวจสอบ Node.js, สร้าง `.env.local` ให้อัตโนมัติ, ติดตั้งแพ็กเกจ และเปิดบราวเซอร์ไปที่ `http://localhost:3000` ทันที!

### สำหรับ macOS / Linux:
- เปิด Terminal แล้วพิมพ์:
  ```bash
  chmod +x start.sh
  ./start.sh
  ```

---

## วิธีที่ 2: รันผ่าน Docker (สำหรับนำไปรันบน VPS / Server) 🐳

รันคำสั่งเดียวผ่าน Docker Compose:
```bash
docker compose up -d --build
```
ระบบจะคอมไพล์เป็น Production Container ด้วย Node 22 Alpine ขนาดเบา และเปิดพอร์ต `3000` ทันที

---

## วิธีที่ 3: Deploy ขึ้น Cloud Hosting (Vercel / Cloudflare) ☁️

1. ติดตั้ง Vercel CLI: `npm i -g vercel`
2. พิมพ์คำสั่ง:
   ```bash
   vercel --prod
   ```
ระบบจะอัปโหลดและเปิดออนไลน์บน URL ทันที
