# ComproNext

ComproNext เป็นเว็บสำหรับจัดสเปกคอม จัดห้องคอม และเทียบราคาสินค้าจากหลายร้านในที่เดียว ใช้ภาษาไทย ทำมาให้ใช้บนมือถือเป็นหลัก



## ฟีเจอร์หลัก

| หมวด | ทำอะไรได้ | หน้า |
|---|---|---|
| จัดสเปกคอม 3D | เลือกชิ้นส่วน ดูเคสแบบ 3D หมุนได้ ระบบเช็กว่าชิ้นส่วนเข้ากันได้ไหม (ซ็อกเก็ต ขนาดเคส กำลังไฟ) และประมาณ FPS 10 เกม | `/builder` |
| สอนประกอบคอม | ดูการประกอบใน 3D ทีละขั้น ชิ้นส่วนลอยลงไปใส่ตามลำดับ | `/builder` → สอนประกอบ |
| ช่วยจัดสเปกให้ | ใส่งบกับเกมที่เล่น ระบบหาชุดที่ได้ FPS สูงสุดและเข้ากันได้ทุกชิ้น | `/builder` → ช่วยจัดสเปกให้ |
| อัปเกรดเครื่องเดิม | บอกว่าควรเปลี่ยนชิ้นไหนก่อนถึงจะคุ้มที่สุด | `/builder` |
| ฉากห้องเกม 3D | วางคอมบนโต๊ะในห้องจำลอง มีไฟ RGB เปิด/ปิดเครื่อง มุมนั่ง และถ่ายรูปได้ | `/builder` |
| เลือกจอ | กรองจอตามการใช้งาน ดูความคม (PPI) และเทียบได้ 3 รุ่น | `/monitors` |
| เปรียบเทียบสเปก | เทียบได้ 4 ชิ้น บอกตัวที่ดีกว่าทีละหัวข้อ สรุปตัวถูกสุด ตัวแรงสุด และตัวคุ้มสุด | `/compare` |
| AI จัดห้อง | อัปโหลดรูปห้อง แล้ว AI แนะนำการจัดพร้อมสินค้า | `/design` |
| จัดห้อง 3D | ใส่ขนาดห้อง แล้ววางของแบบ 3D ของจะไม่ทับกัน | `/design` |
| วัดห้องด้วยกล้อง | ใช้ AR บนมือถือ หรือถ่ายรูปคู่กับกระดาษ A4 เพื่อหาขนาดห้อง | `/design` |
| ไอเดียห้อง | รวมห้องตัวอย่าง พร้อมรายการของที่ซื้อได้จริง | `/rooms` |
| ร้านค้า/พาร์ตเนอร์ | ร้านลงสินค้าเอง อัปโหลด CSV ได้ และซื้อโฆษณาดันสินค้าผ่านพร้อมเพย์ | `/partner` |
| หลังร้าน (Admin) | จัดการสินค้า บัญชีแอดมิน บันทึกการใช้งาน สำรองข้อมูล และหารูปสินค้าจริง | `/admin` |
| บัญชีผู้ใช้ | เข้าสู่ระบบด้วยรหัส OTP ทางอีเมล (มี LINE/Google เป็นทางเลือก) ใช้รายการโปรดและตะกร้าได้ทุกเครื่อง | `/login` |
| อื่นๆ | ติดตามราคา, ประวัติราคา, ชุมชนแชร์ห้อง, แชทกับร้าน, คืนสินค้า, ใช้ออฟไลน์ (PWA), ธีมมืด | — |

## เทคโนโลยี

- **ระบบหลัก:** Next.js 16 (App Router), React 19, TypeScript
- **หน้าตาเว็บ:** Tailwind CSS v4
- **3D:** three.js (เคส โต๊ะ ห้อง และไฟ RGB สร้างด้วยโค้ดทั้งหมด ไม่ได้ใช้ไฟล์โมเดล)
- **AR:** WebXR (hit-test) สำหรับวัดห้อง
- **ฐานข้อมูล:** Postgres บนเว็บจริง / SQLite + JSON ตอนพัฒนาในเครื่อง
- **เก็บไฟล์:** Vercel Blob (รูปสินค้า รูปห้อง)
- **อีเมล:** Gmail SMTP / Clerk (ส่งรหัส OTP)
- **AI:** Cloudflare Workers AI (สร้างรูปห้อง)
- **โฮสต์:** Vercel (เซิร์ฟเวอร์สิงคโปร์) มีงานตั้งเวลา 3 งาน: อัปเดตราคา, สำรองข้อมูลและหารูปจริง, ส่งสรุปรายสัปดาห์

## ความปลอดภัย

- **ล็อกอิน:** ใช้รหัส OTP 6 หลักทางอีเมลอย่างเดียว ไม่เก็บรหัสผ่านผู้ใช้ และรหัสผูกกับอีเมลที่ส่งไปเท่านั้น
- **กันบอท:** ต้องยืนยันว่าไม่ใช่บอทก่อนขอรหัส และจำกัดจำนวนครั้งต่อ IP
- **หลังร้าน:** แยกสิทธิ์ superadmin / admin เข้ารหัสผ่านด้วย PBKDF2 ล็อกบัญชีเมื่อกรอกผิดหลายครั้ง และบันทึกทุกการกระทำ
- **คุกกี้ session:** เข้ารหัส AES-256-GCM ตั้งเป็น httpOnly
- **ข้อมูลส่วนบุคคล (PDPA):** มีป้ายขอความยินยอมคุกกี้ ผู้ใช้ดาวน์โหลดหรือลบข้อมูลตัวเองได้

## ติดตั้ง

**Windows (ง่ายสุด):** ดับเบิลคลิก `deploy.bat` แล้วตอบคำถามตามที่ขึ้น ระบบจะตั้งค่าและขึ้นเว็บบน Vercel ให้

ถ้าจะแก้ค่าภายหลัง ใช้ `change-settings.bat`

**รันในเครื่องสำหรับพัฒนา:**

```bash
pnpm install
pnpm dev          # http://localhost:3000
pnpm build && pnpm start
```

ค่าที่ต้องตั้ง (ตั้งผ่าน `deploy.bat` ได้):

| ค่า | ใช้ทำอะไร |
|---|---|
| `ADMIN_SESSION_SECRET` | กุญแจเข้ารหัสคุกกี้ (บังคับต้องมีบนเว็บจริง) |
| `ADMIN_EMAILS` | อีเมลเจ้าของเว็บที่เข้าหลังร้านได้ |
| `DATABASE_URL` | Postgres |
| `BLOB_READ_WRITE_TOKEN` | Vercel Blob |
| `GMAIL_USER` / `GMAIL_APP_PASSWORD` | ส่งอีเมล OTP |
| `CLOUDFLARE_ACCOUNT_ID` / `CLOUDFLARE_API_TOKEN` | AI จัดห้อง |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | เข้าสู่ระบบด้วย Google (ไม่บังคับ) |

